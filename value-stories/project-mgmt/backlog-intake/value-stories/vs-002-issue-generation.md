  as_a: "Technical Project Manager"
  i_want: >

## INSTRUCTIONS: The Core Algorithm (Execution Logic)

```yaml
instructions:
  reasoning_pattern: "Chain-of-Thought"
  execution_steps:
    - step: 1
      action: "Analyze the 'extracted_issues' report. Identify each unique issue proposal and extract its Title, Description (Body), and Labels."
      validation_rule: "All issues are parsed and ready for creation."

    - step: 2
      action: |
        For each extracted issue, ACTUALLY INVOKE the MCP tool 'create_github_issue'.
        DO NOT write Python code to simulate it. DO NOT say you will do it later.
        Call the tool now for each item using the following parameters:
        
        Use the Owner and Repo from the 'target_repo_info' asset.
        Arguments:
          owner: [Owner from target_repo_info]
          repo: [Repo from target_repo_info]
          title: [Extracted Title]
          body: [Extracted Body]
          labels: [Extracted Labels]
      validation_rule: "The agent triggers the tool call and receives a real API response (e.g., 'SUCCESS: Issue created at...')."

    - step: 3
      action: "Generate a summary report listing the URLs of the created issues."
      validation_rule: "The final output confirms success with direct links."
```
